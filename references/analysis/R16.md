## Signature techniques (reusable)
1. **CRT screen container** (0–8.9 s): render the edit into a rounded, barrel-distorted rectangle on black; animate the container itself (tilt 3–5°, squash to a strip, rotate 30° + overexpose) as transitions. Suits retro/storybook intros.
2. **Object-aligned type** (0.3–1.4 s, 2.0–3.3 s): set words along a prop's axis (guitar neck) or on drawn lines; type-on letter by letter.
3. **Chat-bubble lyrics** (12.0–13.4 s): each word in a messenger bubble (blue = sent, grey = received), popping in with slight rotation, a character cut-out peeking over the last bubble.
4. **Poster card with mixed-script type** (13.4–15.2 s): heavy condensed title above a framed eye crop, vertical Japanese label, zoom out→in with extra sketch cards sliding behind.
5. **Photo-wall fill** (15.2–18.3 s): grid of empty frames on a dark bokeh shelf; each frame receives a still on a beat — a montage without cuts. For football: a wall of trophies/moments filling per beat.
6. **Sticker outline**: 6–10 px white offset stroke + hard shadow on roto cut-outs.
